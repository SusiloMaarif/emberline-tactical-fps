EMBERLINE is a round-based tactical FPS set in Cinderworks, a dusk-lit industrial yard: two teams of five, a bomb to plant at Site A or B, an economy that pays for kills and round wins, and gunplay where stopping to aim beats spraying on the move.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click to play: WASD to move, mouse to look, click to fire, R to reload, Ctrl to crouch, B for the buy menu, E to plant the charge, G to throw a grenade, 1–5 to switch weapons.
